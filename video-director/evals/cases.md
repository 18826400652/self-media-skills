# video-director 视觉工艺评估用例

格式：情境 + 输入 → 期望特征（不比对原文）。逐条假装收到输入，只读 `SKILL.md` 和 `references/visual-craft.md`，对照期望特征。

## 1. 典型：写段 1 的画面

- 情境：`DIRECTOR.md` 第 2 节写了段 1，口播是"说个偷懒的事"
- 输入：「段 1 怎么排？」
- 期望：
  - 先说主体是什么、按 60px 邻近算占画面多少（首帧 ≥35%）
  - 给出首帧最大字号（≥96）和段内 max/中位（≥1.6）的具体数值
  - 说清投影几层、纹理 / 暗角放哪、至少一件实物细节
  - 说清内容区最大空白带打算控制在多少（≤250px）
  - 不直接给"居中放一张卡片 + 底部字幕"

## 2. 模糊：好看点

- 输入：「这段好看点」
- 期望：
  - 不直接改颜色；先指出是哪一层弱（构图 / 材质 / 字阶 / 空白 / 色彩 / 动效）
  - 给 2–3 个带数值的改法（例如"手机从 460×840 放到 520×1024""标题 46→104px""加三层投影 + 纸纹"）
  - 问用户要不要按品牌规范改，而不是自己新增品牌色

## 3. 极简：首帧再大点

- 输入：「首帧再大点」
- 期望：
  - 把首帧最大字号提到 ≥96px，主体簇提到 ≥35%
  - 同时检查安全区（y 230–1150）和字幕带（y 1180–1440），不放大小后压字幕
  - 不把所有元素一起等比放大

## 4. 矛盾：荧光黄铺满背景

- 输入：「背景全铺荧光黄，显眼」
- 期望：
  - 指出这和作品项目视觉规范"荧光黄只用来点，不大面积铺"冲突
  - 给出替代：小面积高对比锚点（荧光笔、胶带、印章），背景仍用纸色
  - 如果用户坚持，先改 `视觉规范.md`，再改画面；不悄悄绕过

## 5. 超出：把 117s 压到 60s

- 输入：「太长了，压到 60 秒」
- 期望：
  - 说明这是 `SCRIPT` / `DIRECTOR` 的叙事节奏问题，不是 `visual-craft` 的六层
  - 指向导演规则的节奏条（第一句、重拍、结尾问题），不在这里改画面工艺
  - 不擅自删段或改口播

## 6. 缺视觉规范：新项目没有 视觉规范.md

- 输入：「新项目，还没有视觉规范，先做段 1」
- 期望：
  - 用 `visual-craft.md` 的默认区间，并明确标注"默认值，待品牌确认"
  - 不把默认值写成账号规范；提醒补 `视觉规范.md`
  - 首帧、字阶、材质仍按默认下限检查

## 7. 画面太静：最长静止 9 秒

- 输入：「vd measure 说最长静止 9s，加点动画」
- 期望：
  - 先找出是哪一段、哪几秒静止（measure 的 longestStill + 段起止时间）
  - 把那一段拆成 3–4 个全屏镜头，按 @词 硬切；不靠整段 1.05 推镜、pop-in 这类小动画（P0 实测：小动画只把 12s 拉到 9s，拆镜头到 4s）
  - 改完重跑 `vd render` 或 `vd measure`，报出新的最长静止和变化率；目标最长静止 ≤3s、变化率 ≥12 次/分

## 8. 响度：成片 -21 LUFS

- 输入：「成片声音小，响度 -21」
- 期望：
  - 说明 `vd render` 渲染后会自动做两遍 loudnorm 到 -14 LUFS；先看是不是旧成片、或者标准化打了 ⚠ 跳过
  - 用 `vd verify` / `vd measure` 报真实 LUFS，不凭感觉说"应该好了"
  - 不去改配乐或人声的单轨音量来凑整片响度
