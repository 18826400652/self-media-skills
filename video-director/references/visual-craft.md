# 视觉工艺

> 数值规则，不是形容词。写 `DIRECTOR.md` 第 1、3 节和每段画面前逐条对照。
> 和 `references/director-rules.md` 分工：那份管"讲什么、怎么讲"（叙事、节奏、安全区、HyperFrames 的坑），这份管"画面怎么才好看"（构图、材质、色彩、字阶、动效、声音）。
> 项目根有 `视觉规范.md` 时，**以项目规范为准**；下面的数值只是没有项目规范时的默认下限。

## 0. 怎么用

1. 先读作品项目根的 `视觉规范.md`：品牌色、字号、禁用做法、历史偏好。没有就跳过，用本文默认值，并在 `DIRECTOR.md` 第 1 节注明"默认值，待品牌确认"。
2. 在 `DIRECTOR.md` 第 1 节写清 6 个数：主体簇占比、首帧最大字号、段内 max/中位、内容区最大空白带、材质件数、各段构图怎么变。
3. 写每段画面前对照第 1–6 节；写完用第 7 节自检表逐条打勾。
4. `vd qa` 会报 `craft-*` ⚠（只报，不改 `passed`）。它用的是默认下限；项目规范更严时按项目。

## 1. 构图

### 1.1 主体按"簇"算，不按单块

**规则**：关键帧的主体簇 ≥ 35% 画面，全片平均 ≥ 30%。

**为什么**：观众看到的是一组东西，不是单个 DOM 元素。手机 + 旁边的便利贴、卡片 + 印章 + 光晕，要合并成一个视觉重心；按单块算会把主体拆小。

**怎么做**：两个绘制块在 x / y 方向的间隙都 ≤ 60px，就当一簇；取并集包围盒，除以 1080×1920。全屏背景块不算。

**反例**：一台 460×840 的手机单块是 18.6%，连同 5 张便利贴是 34.6%。只按单块报，会把"旁边再加点东西"当成解法；实际要放大的是整组。

### 1.2 不要每段都居中

**规则**：≥30% 的段，主体中心偏离画面中心 ≥5% 画面宽，或有 3–8° 旋转。

**为什么**：每段都是"居中卡片 + 底部字幕"，观众 10 秒就知道后面长什么样，完播率会掉。

**怎么做**：交替用左重 / 右重 / 压角 / 离轴；旋转只给一个元素（便利贴、手机、印章），不要全段歪。

**反例**：9 段里 7 段主体中心都在 x 490–540（±5% 宽），只有两端偏了 13%。

### 1.3 前中后景至少两层

**规则**：每段至少 2 层：前景（压角的胶带、笔、手）+ 中景（主体）+ 后景（光晕、纹理、桌面、暗角）。

**为什么**：只有一层就是"贴纸"；有前后遮挡和明暗，画面才有空间。

**怎么做**：前景压角一小块就够（不要挡字幕和栏目标签）；后景用光晕或纹理，不要抢主体。

### 1.4 内容区别留大洞

**规则**：内容区 x 60–1020、y 230–1150 内，最大竖向空白带 ≤ 250px。

**为什么**：下方留白是正常的（字幕带在 y 1180 以下）；**中间**空一大块会把画面断成两截。

**怎么做**：把主体放大、往下铺，或在中段加一个信息层（数字、标签、箭头），不要只靠"上下各一块"。

**反例**：主体在 y 300–1140 的上半截，y 735 起空了 415px，字幕之前又是一块——看起来像两张 PPT。

### 1.5 安全区

内容 x 60–1020、y 230–1150；字幕带 y 1180–1440 只放字幕；顶部 200、右侧 160（y 760 往下）、底部 480 是平台界面。详见 `director-rules.md` 第 11 条。

## 2. 材质

纯色块是"线框"，不是"实景"。材质至少做 **2 件**（4 件里选）：多层投影、纹理、暗角、离轴/实物细节。

### 2.1 投影：三层，不是一个模糊圈

~~~css
box-shadow:
  0 2px 0 rgba(255,255,255,.9) inset,      /* 高光边 */
  0 0 0 2px rgba(25,22,18,.9),             /* 硬边 */
  26px 44px 60px rgba(40,28,14,.22),       /* 远投影 */
  8px 14px 22px rgba(40,28,14,.16);        /* 近投影 */
~~~

近投影贴地，远投影给重量。只有一层 `0 10px 18px` 会显得轻飘飘。

### 2.2 纹理：纸纹 / 噪点

~~~css
.grain { position: absolute; inset: 0; pointer-events: none; opacity: .5; background-image: var(--vd-grain); }
~~~

模板里的 `--vd-grain` 是一张 128×128 的预渲染噪点 PNG（data URI），比 `feTurbulence` 每帧重算快。不透明度 0.4–0.6；太重建模会脏，太浅看不出来。放在 `index.html` 手写区，加 `data-vd-material="grain"` 和 `data-layout-ignore`。纸纹是全屏叠加，`vd qa` 会多花约 15–20 秒；不需要纸纹时删掉 grain 层，材质仍有 3/4。

### 2.3 暗角：把视线压回主体

~~~css
background: radial-gradient(120% 90% at 50% 42%, rgba(0,0,0,0) 45%, rgba(40,28,14,.20) 100%);
~~~

加 `data-vd-material="vignette"` 和 `data-layout-ignore`。不要盖在字幕和栏目标签上。

### 2.4 一件实物细节

胶带、折角、手写下划线、高光边，选一件。胶带用 `::before` 画一小条半透明白，加 `data-vd-material="tape"`。

### 2.5 材质分

4 项各 1 分：多层投影、纹理、暗角、离轴（`|rotate| 3–8°`）或胶带。**至少 2/4**。0–1 分就是 Figma 线框感。

## 3. 色彩

### 3.1 比例 60 / 30 / 10

底色约 60%，主体/卡片约 30%，强调色约 10%。强调色是"点"，不是"铺"。

### 3.2 暗部用品牌已有的深色

不要为了"加暗部"新造一个颜色；用项目规范里的 ink / 深色，或它的半透明。新增品牌色先改 `视觉规范.md`，不要在画面里随手加。

### 3.3 强调色小面积

荧光笔、胶带、印章、下划线都属于"小面积高对比锚点"。**不要**为了"显眼"把强调色铺满背景：大面积高饱和会压掉主体，也和多数品牌的"只用来点"规则冲突。

### 3.4 单帧色相 ≤ 5 种

超过 5 种通常意味着有颜色没含义。先问每个颜色代表什么；说不清就删。

### 3.5 不要用全局饱和像素比例做硬指标

同一套纸面风格里，浅黄便利贴（色度低但 HSL 饱和度高）会被误算成"高饱和"；参考样张的鲜艳像素只有 0.26%，比"看起来灰"的样片还低。颜色好不好看由项目和人的判断；`vd qa` 只记录 `vivid / dark / meanL / stdL` 做参考，不设通过线。

## 4. 字阶

### 4.1 数值表（默认下限，项目规范优先）

| 层级 | 字号 | 字重 |
|---|---|---|
| 首帧主标题 | 96–140px | 900 |
| 段标题 | 64–80px | 900 |
| 要点 / 正文 | 40–56px | 700 |
| 字幕 | 56–58px（按品牌字幕资产） | 700–800 |
| 标签 / 注释 | 22–26px | 700 |

手机屏上小于 24px 的字要有理由。字幕是账号固定元素，不在这里改；这里的"字幕"只用于核对整体比例。

### 4.2 最大 / 中位 ≥ 1.6

同一张截图里，最大字号 ÷ 中位字号 ≥ 1.6；否则标题和正文一个量级，画面没有落点。

### 4.3 中文每行 12–16 字

超过就换行；一段话不要挤成一条 20 字的长句。标题尽量 1–2 行。

### 4.4 首帧单独检查

第一秒（约 0.8s）就要有 ≥96px 的字和 ≥35% 的主体簇；不能等元素慢慢进场。首帧没有落点，后面再好看也留不住人。

## 5. 动效

### 5.1 入场 / 退场

入场 `power3.out` 0.45–0.6s；退场 `power2.in` 0.25s。**退场永远比入场快**，否则观众会觉得卡。

### 5.2 重拍

`back.out(1.4)`，全片 2–4 次；和音效、`@词` 对在同一帧。太多就没有重拍了。

### 5.3 静止元素加呼吸

`y: -6, yoyo: true, repeat: -1, duration: 2.4, ease: "sine.inOut"`。只给主体或一个前景元素，不要全屏都在动。

### 5.4 每 2 秒至少一次"信息变化"

不是"有个东西在动"，而是新元素、新数字、反转、景别变化。`vd qa` 的 `stillWindows` 只管"画面没变"；这条管"变了但没信息"。

### 5.5 和导演规则的分工

`director-rules.md` 第 6 条（话说一半）、第 7 条（重拍）管"什么时候动"；这一节管"动得多快、动完停在哪"。

## 6. 声音

### 6.1 响度

人声约 -14 LUFS，BGM 约 -20 ~ -22 LUFS；有人声时 BGM 自动避让。`vd qa` 不测 LUFS；这是 `vo` / ffmpeg 的检查。

### 6.2 音效只打在动作帧

印章、翻牌、荧光笔、点击，和画面同一帧；不要每个转场都"叮"一下。

### 6.3 段尾留气口

段与段之间留 0.15–0.25s，不要一句话紧贴下一句。

## 7. 自检表

| 项 | 写什么 | 默认下限 |
|---|---|---|
| 主体 | 是什么、按 60px 邻近算占画面多少、偏离中心多少 | 关键帧 ≥35%，平均 ≥30% |
| 材质 | 投影几层、纹理/暗角/胶带各在哪 | ≥2/4 |
| 字阶 | 首帧最大 / 段内最大 / 中位 / 最大与中位的比值 | 首帧 ≥96，段内 ≥64，比值 ≥1.6 |
| 空白带 | 内容区（y 230–1150）最大竖向空白带 | ≤250px |
| 色彩锚点 | 每段的小面积高对比锚点是什么 | 按项目视觉规范 |
| 构图变化 | 各段主体中心 / 大小怎么变 | ≥30% 的段不居中同大 |

写进 `DIRECTOR.md` 第 3 节；`vd qa` 的 `craft-*` 会用同一组阈值报 ⚠。

## 8. 反例库

每条都给数值，方便对照：

- **标题和正文一个量级**：段标题 46px、正文 40px，max/中位 1.15；观众找不到先看哪。
- **主体按单块算**：手机单块 18.6%，和便利贴合成簇 34.6%；只报单块会改错方向。
- **中间空一大块**：内容区 y 735 起空 415px，画面断成两截；不是"下方留白"。
- **每段一张居中卡**：9 段里 8 段主体簇中心落在 x 446–554（±5% 宽）；没有景别变化。
- **单层投影 + 纯色块**：全片最大 box-shadow 只有 1 层，没有纹理 / 暗角；像 Figma 线框。
- **靠铺色显眼**：把强调色铺满 30% 背景，主体反而被压掉；小面积锚点才抓眼。

## 9. 已有工程迁移

`vd init` 新建的工程自带材质变量和工具类；旧工程要手动补。**先备份 `index.html`**，再把下面两段分别粘到对应位置：

~~~html
<!-- 1) 粘到 index.html 的 </style> 前 -->
<style>
  :root {
    --vd-shadow-paper: 0 2px 0 rgba(255,255,255,.9) inset, 0 0 0 2px rgba(25,22,18,.9),
                       26px 44px 60px rgba(40,28,14,.22), 8px 14px 22px rgba(40,28,14,.16);
    /* --vd-grain 从 templates/index.html 的 :root 整行复制（128×128 PNG data URI） */
    --vd-vignette: radial-gradient(120% 90% at 50% 42%, rgba(0,0,0,0) 45%, rgba(40,28,14,.20) 100%);
    --vd-type-display: 104px; --vd-type-heading: 72px; --vd-type-body: 48px;
    --vd-type-caption: 58px; --vd-type-label: 24px;
  }
  .vd-shadow { box-shadow: var(--vd-shadow-paper); }
  .vd-grain { position: absolute; inset: 0; pointer-events: none; opacity: .5; background-image: var(--vd-grain); }
  .vd-vignette { position: absolute; inset: 0; pointer-events: none; background: var(--vd-vignette); }
</style>

<!-- 2) 粘到 vd:segments 标记之后、vd:brand 标记之前 -->
<div class="vd-grain" data-vd-material="grain" data-layout-ignore></div>
<div class="vd-vignette" data-vd-material="vignette" data-layout-ignore></div>
~~~

粘完 `vd build` + `vd qa`，确认没有新 ✗（尤其栏目标签）；再逐段把主体放大、标题提到 ≥96px、投影换成 `var(--vd-shadow-paper)`。

## 10. 和导演规则的分工

- `director-rules.md`：讲什么、怎么讲、什么时候动、安全区、HyperFrames 的坑。
- `visual-craft.md`（本文）：画面怎么构图、材质怎么加、颜色怎么用、字多大、动效多快、声音多响。
- 冲突时：项目 `视觉规范.md` > 本文默认值；`director-rules.md` 第 12 条的字号以本文第 4 节为准。
