# content-repurpose：一份母稿，多平台输出

## 原则

1. **母稿是唯一事实来源**。各平台版本只改形式，不新增事实；要补内容，先补到母稿里。
2. **按平台的消费场景重写，不要压缩原文**：
   - 公众号是「坐下来读」：完整、有逻辑。
   - 小红书是「刷到就存」：一眼看懂、可收藏。
   - 抖音是「划走之前」：3 秒抓人、一句一个画面。
3. **每个版本只保留一个核心信息**，其余内容服务于它。
4. 改编顺序建议：**母稿 → 公众号 → 小红书 → 抖音**，从完整到精炼，越往后删得越多。

## 平台对照

| | 公众号 | 小红书 | 抖音 / 视频号 |
|---|---|---|---|
| 形式 | 长文 | 6-9 张卡片 + 文案 | 30-90 秒竖屏视频 |
| 篇幅 | 1500-3000 字 | 卡片每张 ≤120 字；文案 ≤1000 字 | 口播 150-400 字 |
| 标题 | ≤ 30 字，信息量足 | ≤ 20 字，口语、带情绪或数字 | 封面字 ≤ 12 字 |
| 开头 | 100 字内说清收获 | 封面就是开头 | 前 3 秒钩子 |
| 结构 | 3-5 个二级小节 | 封面 → 要点卡 → 结尾卡 | 钩子 → 铺垫 → 干货 → 收尾 |
| 留存点 | 结尾行动清单 | 收藏价值（清单、模板、对比） | 完播（节奏）+ 评论（提问） |

各平台细则见 `references/` 下的 `wechat.md`、`xiaohongshu.md`、`douyin.md`。

## 改编流程

1. 读母稿，用一句话写出**核心信息**和**目标读者**。写不出来，说明母稿还没想清楚，先回去改母稿。
2. 从母稿里列出**素材清单**：观点、步骤、数据、例子、提示词、踩坑。
3. 按平台挑素材：
   - 公众号：几乎全用。
   - 小红书：挑 3-6 个最容易「存下来」的。
   - 抖音：挑 1 个结论加 2-3 个支撑点。
4. 按对应 reference 的模板写初稿。
5. 逐条过自检清单，再交给成品工具：`wa preview`、`ic render`、`nv`（视频，见 narrated-video）。

## 标题套路（三个平台通用，按平台调整长度）

| 套路 | 例子 |
|---|---|
| 结果前置 | 我用 AI 10 分钟写完了周报 |
| 数字清单 | 5 个让 AI 回答更准的提示词技巧 |
| 反常识 | 提示词写得越长，AI 反而越笨 |
| 痛点 + 方案 | 每周写周报要 1 小时？试试这个 |
| 对比 | 同一个问题，ChatGPT 和 Claude 回答差在哪 |
| 身份共鸣 | 普通人学 AI，先别学这三样 |

不要做标题党：标题许诺的东西，正文必须给到。
