# 小红书

小红书有两种笔记，项目在自己的平台策略里选一种：

- **视频笔记**：发和抖音同一个成片，只另写标题、正文、话题。省一套制作，适合以视频为主的账号。
- **图文笔记**：6-9 张卡片 + 文案，卡片交给 image-cards 渲染。适合清单、合集类，要单独做一套图。

两种都是「刷到就存」：标题和正文负责被搜索到，正文要把视频或卡片里的干货写成能照着做的样子。

## 视频笔记

一篇笔记 = **成片** + **标题** + **正文文案** + **话题标签**。成片不另剪，和抖音同一个文件。

- 视频本身不用改：竖屏 9:16 两边通用；开头钩子、结尾「领」的说法和抖音一致
- 小红书的人更爱搜和存：**正文把视频里的步骤写成文字清单**，看完视频的人能对着正文做，没看视频的人搜到也能用
- 封面：可以用和抖音同一张封面图（`nv draft --cover` 自动上传），小红书按 3:4 裁，9:16 的图只留上面一截，大字放上半部分；不传就用第一帧（可能是黑的）。信息流里缩成小图也要看得清
- 存草稿：`nv draft <成片.mp4> --copy 小红书/文案.md --cover <封面图> --to xiaohongshu`（见 narrated-video）

## 图文笔记（卡片交给 image-cards 渲染）

| 位置 | 内容 | 要点 |
|---|---|---|
| 第 1 张 封面 | 大标题 + 一行副标题 | 标题 ≤ 15 字，加粗一个关键词；信息流里缩成小图也要看得清 |
| 第 2-8 张 内容 | 每张一个要点：小标题 + 3-5 条 | 单张 ≤ 120 字；多用列表、对比、代码块；必要时用一张金句卡调节节奏 |
| 最后一张 结尾 | 总结或关注引导 | 「收藏备用」「关注看下一期」 |

**收藏价值最高的形式**：清单、步骤、模板、提示词合集、前后对比、避坑指南。

## 标题（≤ 20 字，两种笔记通用）

- 口语化，像朋友分享：「终于搞懂了」「后悔没早点知道」
- 带数字或结果：「3 个」「10 分钟」「省了一半」
- 可以加 1 个 emoji，不要堆叠
- 带上读者会搜的关键词，比如「AI」「提示词」「效率」

## 正文文案（≤ 1000 字，建议 300-600 字）

文案文件按 `## 标题`、`## 正文`、`## 话题` 分段（`nv draft` / `ic draft` 都按这个格式读）：

```
（第一句：说清这篇解决什么问题，直接给结论）

（3-5 个要点或步骤，每点 1-2 句；可用 emoji 或序号开头。视频笔记写视频里的步骤，图文笔记写卡片里没放下的细节）

（结尾：互动提问，如「你平时用 AI 做什么？」，或者「收藏起来下次用」）

#话题1 #话题2 #话题3 …（5-10 个，大词和细分词混搭，如 #AI #AI工具 #提示词技巧 #效率提升）
```

## 平台注意

- 不要放二维码、微信号、站外导流，容易被限流
- 涉及具体产品时写真实体验，避免硬广语气
- 画面、卡片和正文里不要出现「最」「第一」等绝对化用语
- AI 生成的视频或图片，发布时勾选平台的 AI 内容声明

## 自检

- [ ] 标题 ≤ 20 字，含搜索关键词
- [ ] 正文第一句就有价值，结尾有互动
- [ ] 话题标签 5-10 个
- [ ] 视频笔记：正文里有能照着做的步骤清单，不只是「看视频」；选好了清楚的封面帧
- [ ] 图文笔记：封面缩成小图时标题仍然一眼能读；每张内容卡只讲一件事，`ic render` 没有溢出警告
