# 小红书图文

一篇笔记 = **卡片（图）** + **标题** + **正文文案** + **话题标签**。卡片负责被看见和被收藏，文案负责补充信息和被搜索到。

## 卡片（交给 image-cards 渲染）

| 位置 | 内容 | 要点 |
|---|---|---|
| 第 1 张 封面 | 大标题 + 一行副标题 | 标题 ≤ 15 字，加粗一个关键词；信息流里缩成小图也要看得清 |
| 第 2-8 张 内容 | 每张一个要点：小标题 + 3-5 条 | 单张 ≤ 120 字；多用列表、对比、代码块；必要时用一张金句卡调节节奏 |
| 最后一张 结尾 | 总结或关注引导 | 「收藏备用」「关注看下一期」 |

**收藏价值最高的形式**：清单、步骤、模板、提示词合集、前后对比、避坑指南。

## 标题（≤ 20 字）

- 口语化，像朋友分享：「终于搞懂了」「后悔没早点知道」
- 带数字或结果：「3 个」「10 分钟」「省了一半」
- 可以加 1 个 emoji，不要堆叠
- 带上读者会搜的关键词，比如「AI」「提示词」「效率」

## 正文文案（≤ 1000 字，建议 300-600 字）

```
（第一句：说清这篇解决什么问题，直接给结论）

（3-5 个要点，每点 1-2 句；可用 emoji 或序号开头，卡片里没放下的细节写在这里）

（结尾：互动提问，如「你平时用 AI 做什么？」，或者「收藏起来下次用」）

#话题1 #话题2 #话题3 …（5-10 个，大词和细分词混搭，如 #AI #AI工具 #提示词技巧 #效率提升）
```

## 平台注意

- 不要放二维码、微信号、站外导流，容易被限流
- 涉及具体产品时写真实体验，避免硬广语气
- 卡片和正文里不要出现「最」「第一」等绝对化用语

## 自检

- [ ] 封面缩成手机信息流的小图时，标题仍然一眼能读
- [ ] 每张内容卡只讲一件事，`ic render` 没有溢出警告
- [ ] 标题 ≤ 20 字，含搜索关键词
- [ ] 正文第一句就有价值，结尾有互动
- [ ] 话题标签 5-10 个
