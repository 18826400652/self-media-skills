# {{账号}} · 自媒体作品项目

观众：{{观众}}（定位见 `00-规划/账号定位.md`）。三个平台：**抖音**（不出镜：AI 动画 + AI 配音）、**公众号**（长文）、**小红书**（发和抖音同一个视频，另写文案）。

## 核心思路：一个选题，三个平台

```
选题（03）→ 选题关 → 实测 → 母稿 → 抖音视频 / 公众号 / 小红书（04/<作品>/）→ 存草稿 → 发布 → 复盘（07、经验库）
```

作品按**选题**组织，不按平台组织：一个选题一个文件夹，所有平台版本都在里面。一期有十几步，由 `kv status` 管；每一步怎么做、调哪个 skill，见工具包 studio skill 的 `references/workflow.md`。

## 作品项目和工具包分开

这个目录只放**内容**：选题、母稿、成片源码、品牌、账号配置。做内容用的工具（各 skill 和命令 `st` `kv` `sc` `nv` `vd` `wa` `ic` `bd` `pd`）在单独的工具包里。

- `studio.json` 是作品项目的标记，写目录约定和账号信息；各 skill 的项目配置是根目录的 `<skill>.config.json`
- 密钥放 `.env`（复制 `.env.example` 再填，不会提交）
- 第一次用或换机器：在工具包里 `studio/bin/st install --deps`，再回到这里 `st doctor`，按提示补齐

## 目录

| 目录 | 放什么 | 多久动一次 |
|---|---|---|
| `00-规划/` | 账号定位、语气指南、`系列/` 系列规划和登记表、`经验库/` | 偶尔 |
| `01-灵感收集/` | `inbox.md`：随手记的链接、想法，不整理 | 每天 |
| `02-学习笔记/` | 按主题沉淀的知识，内容的「原矿」 | 每天 |
| `03-选题池/` | `选题清单.md`：选题标准和待做的题 | 每周 |
| `04-作品/` | 按系列组织：`<系列>/NN-简称/`，单篇放 `单篇/YYYY-MM-DD-简称/` | 每期 |
| `05-模板/` | **只放改过的模板**（默认模板在工具包 `studio/templates/`，同名文件放这里就覆盖默认的） | 偶尔 |
| `06-品牌资产/` | 品牌主题（`theme.css` 封面卡片用；`hyperframes/` 视频里账号固定元素：栏目标签、字幕、结尾）、参考音色、音效 | 偶尔 |
| `07-复盘/` | 每周的数据复盘 | 每周 |

01、02、03、07 只给人用，工具不读。

## 做一期内容

```bash
st new <系列> <简称>                     # 新建一期（系列先在 00-规划/系列/系列.json 登记）
kv status 04-作品/<系列>/01-<简称>        # 每一步开始前先跑：列出步骤和下一步
```

确认节点（kv status 会提示）要你明确说「通过」才往下走。三个平台**只存草稿，不自动发布**。

## Git 约定

- 文字、HTML 动画源码、小图片入库；**视频、配音、录屏原片不入库**（见 `.gitignore`），成品另存网盘。
- 视频都能从源码重新渲染，所以仓库保存的是「视频源码」。
