# 视觉规范

> 三个平台共用一套视觉，形成辨识度。下面是 `st init` 给的起步配色，换成自己的品牌色时，这里和代码要一起改：
> - `theme.css`：封面卡片（`ic`）用
> - `hyperframes/brand-*.html`：视频里账号固定元素（栏目标签、字幕、结尾）的样式
> - 公众号排版用 `wechat-article.config.json` 的 `theme`（工具包自带的主题）

## 风格方向

（一句话说清楚你的视觉感觉，例如：「深色背景上的笔记感，重点词像被荧光笔划过」）

## 配色

| 名称 | 色值 | 用途 |
|---|---|---|
| 背景 `--bg` | `#101114` | 背景 |
| 主文字 `--fg` | `#F4F1EA` | 主文字 |
| 高亮 `--highlight` | `#FFD84D` | 重点词、关键数字（只用来点，不大面积铺） |
| 强调 `--accent` | `#6EA8FE` | 次级强调、图形、链接 |
| 警示 `--danger` | `#FF5A5F` | 出错、翻车、红圈 |
| 辅助文字 `--fg-muted` | `#8A8D96` | 说明文字 |
| 卡片底 `--surface` | `#1B1D22` | 卡片、代码块底色 |

## 字体

- 中文：思源黑体 / Noto Sans SC（开源可商用，video-director 自带）
- 代码：JetBrains Mono

## 字号（1080×1920 画布）

| 用途 | 字号 |
|---|---|
| 大标题 | 110–140px |
| 要点 | 64–80px |
| 字幕 | 56px |
| 说明文字 | 40px |

## 目录说明

- `theme.css`、`hyperframes/`：见上
- `参考音色.wav`：配音克隆用的参考音频（自己准备，30 秒以内的干净人声）
- `音效/`：转场音效、BGM（只用可商用素材）
