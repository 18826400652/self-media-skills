# 项目说明（给 AI 助手）

自媒体**作品项目**（账号：{{账号}}；观众：{{观众}}），三个平台：抖音（不出镜：动画 + AI 配音）、公众号（长文）、小红书（发和抖音同一个视频，另写文案）。

工具在工具包里（各 skill 已注册到 `~/.claude/skills/`）。**做任何事之前先读 studio skill**，完整流程见它的 `references/workflow.md`。环境有问题先跑 `st doctor`。

## 做一期内容

- 新建：`st new <系列> <简称>`（导演做法加 `--video director`）；系列登记在 `00-规划/系列/系列.json`。
- **每一步开始前先跑 `kv status <作品目录>`，只做它说的那一步。** 确认节点**用户明确说通过后**才跑 `kv gate <作品> <节点> "用户原话"`，提修改意见用 `--edit`。
- 三个草稿成功后跑 `kv done <作品> wechat|xiaohongshu|douyin`。
- 写任何内容前先读 `00-规划/语气指南.md` 和 `00-规划/账号定位.md`。

## 规矩

- **只存草稿，永远不点发布**；登录、扫码、验证由用户做。
- **实测绝不编造**。
- 出图、出视频后一定要看截图检查。
- 不要提交视频、配音、录屏（`.gitignore` 已排除）。
- 改工具到工具包里改；这里只放内容和项目配置（`studio.json`、`<skill>.config.json`、`05-模板/` 里改过的模板、`06-品牌资产/`）。
