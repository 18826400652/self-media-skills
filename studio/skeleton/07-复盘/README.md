# 复盘

每周一篇，文件名 `YYYY-Www.md`（如 `2026-W41.md`）。数据从各作品的 `发布记录.md` 汇总。

单期的复盘写在 `00-规划/经验库/`（流程最后一步会提醒）；这里放按周汇总的复盘，工具不会读。

## 周复盘模板

```markdown
# 2026-W41 复盘

## 本周发布
| 作品 | 栏目 | 播放 | 完播率 | 点赞 | 涨粉 |
|---|---|---|---|---|---|

## 表现最好的一期，为什么？
## 表现最差的一期，为什么？
## 评论区高频问题（转成选题）
## 流程上的卡点（哪一步最耗时？能不能自动化？）
## 下周调整
```
