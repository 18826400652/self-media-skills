# 公众号策略

> 改编公众号文章前先读这一份。通用写法见工具包 content-repurpose 的 `references/wechat.md`；这里只记本账号的定位和节奏。

## 在矩阵里的角色

（例：深度与沉淀。抖音和小红书负责被看见，公众号负责讲透，把认真的读者留下来。母稿最完整的版本发在这里。）

- 领资料入口：（例：文末写「回复关键词 XX 领模板」）
- 抖音和小红书可以引导「完整版在公众号」，但不要直接写公众号名或放二维码

## 形式

- 图文长文，（例：1500–3000 字）
- 排版主题：`wechat-article.config.json` 的 `theme`；封面用 `ic` 的 `wechat-cover` 预设
- 固定结尾：（例：一句互动提问 + 关注引导）

## 节奏

- 频率：（例：每周 1 篇，和抖音同选题）
- 发布时间：先试晚上 19–21 点，发 3 期后按后台数据调

## 制作

```bash
wa preview 04-作品/<作品>/公众号/文章.md      # 浏览器打开预览
ic render 04-作品/<作品>/公众号/封面/封面.md   # 封面图
wa draft 04-作品/<作品>/公众号/文章.md        # 用浏览器存进公众号后台草稿箱（个人号没有草稿接口）
```
