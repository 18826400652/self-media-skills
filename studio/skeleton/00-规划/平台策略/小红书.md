# 小红书策略

> 改编小红书文案前先读这一份。通用写法见工具包 content-repurpose 的 `references/xiaohongshu.md`；这里只记本账号的定位和节奏。

## 在矩阵里的角色

（例：收藏与搜索。用户会搜具体问题，内容要做成「存下来以后用」的样子：清单、模板、对比。）

## 形式

- **笔记类型**：视频笔记（和抖音同一个成片，只另写 `小红书/文案.md`）。想改成图文卡片就在这里写明，content-repurpose 按这里选
- 正文：把视频里的步骤写成文字清单，存下来能照着做；结尾引导领资料
- 封面：和抖音同一张 `抖音/out/01.png`，`vdraft --cover` 自动上传。网页按 3:4 裁，**封面大字放在上半部分**

## 节奏

- 频率：（例：每周 1 篇，和抖音同选题、同一个视频）
- 发布时间：先试晚上 19–21 点，发 3 期后按后台数据调

## 制作

```bash
vdraft 04-作品/<作品>/抖音/renders/<成片>.mp4 --copy 04-作品/<作品>/小红书/文案.md --cover 04-作品/<作品>/抖音/out/01.png --to xiaohongshu
```

默认用浏览器存进创作服务平台的草稿箱，不点发布。网页草稿只存在这台电脑的浏览器里，不同步到手机 App。

## 数据关注点

| 指标 | 说明什么 |
|---|---|
| 封面点击率（阅读 ÷ 曝光） | 封面和标题是否抓人 |
| 完播率、平均播放时长 | 视频节奏在小红书是否也成立 |
| 收藏 ÷ 点赞 | 收藏高说明干货价值高 |
| 搜索带来的流量 | 关键词选得对不对 |
