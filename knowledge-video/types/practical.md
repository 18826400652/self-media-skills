# 类型档案：实用技巧

教一个马上能用的 AI 用法。

## 真实性靠什么

实测：按 scenario-content 的流程写场景卡、在真实产品里实测，产物 `实测记录.md` + 录屏（`sc rec`）。

整期的顺序和确认由 `kv status` / `kv gate` / `kv done` 管，见 SKILL.md「实用类」一节。

## 结构配方

抖音脚本按 content-repurpose 的 `references/douyin.md`「成品教程结构」：成品亮相 → 你能拿到什么 → 准备 → 三步 → 一个坑 → 怎么避开 → 回到成品 → 领模板。

## 依据怎么标

SCRIPT.md 每句 `**依据:**` 写实测轮次（如 `R1`、`R2`），或 `类比`、`观点`。`kv check` 对实用技巧类只检查依据行存在且非空。

## 常用画面

按段设计的画面（video-director 的导演脚本里写）：聊天钩子、重建 AI 回答（实测原文）、模板卡（结尾）、录屏（`dy-rec-phone`）。
