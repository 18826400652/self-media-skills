# 配音导演稿（VOICE.md）写法

给 `seedaudio`（豆包音频生成模型 Seed-Audio 1.0）用。它不是照字念的 TTS，而是按一段描述去「演」：
描述写得越贴合台词，越像真人在说话。所以每期都要读完口播稿，**按内容**写一份导演稿，不套固定模板。

流程位置：`SCRIPT.md` 定稿 → 写 `VOICE.md` → `nv hf-audio . --check`（只检查，不花钱）→ **给用户看导演稿，确认后**再 `nv hf-audio .`。

## 一份提示由三部分拼成

| 部分 | 写在哪 | 内容 |
|---|---|---|
| 人设和场景 | 项目配置 `tts.style` | 每期都一样：谁在说（年龄、嗓音）、在什么场景（给抖音录口播、对着镜头跟观众聊）、整体状态。程序会在第一个括号里补上「饰演者为@音频1」，绑定 `tts.reference` 的参考音色 |
| 表演说明 + 台词 | `VOICE.md` 每段的代码块 | 本期按内容写的部分，见下文 |
| 约束 | 程序自动加 | 「只说引号里的话，一字不改，不加背景音乐和音效。」 |

## 文件格式

````markdown
# VOICE — 不想看

## 钩子到成果 (Frame 1-4)

```text
开头她带着点不甘心和自嘲，语速稍快地说道："AI帮我做了五条视频，每一项检查都过了。"然后稍微停顿了一下，语气放轻，有点无奈地说："可我自己看完，一条都不想发。"
接着她语气变得真诚，像在问观众，放慢一点说："做得挺认真，自己却刷不下去，你可能也有过。"……
```
````

- 标题写 `## 段名 (Frame 首-末)`，一段覆盖**连续**几帧，每一帧恰好属于一段
- 提示写在 ```` ```text ```` 代码块里，代码块外的文字（备注）不发给模型
- 引号里的台词连起来必须**等于**这几帧的口播原文（标点、空格、英文大小写不算）。`--check` 会逐段核对并指出从哪个字开始不同

## 怎么分段

- 一段 3–5 帧、100–250 字为宜。官方建议一次的台词不超过 400 字，太长模型会自己加快语速
- 按**情绪段落**切，不按帧数平均切：钩子+开场一段、讲过程一段、转折一段、结论+行动一段
- 段内帧与帧之间保留说话本身的停顿（不再加 `--pause`），所以同一口气的内容放一段；需要「换气、画面停一下」的地方切成两段，`--pause` 加在段与段之间
- 改了某帧的台词，只有它所在的那一段要重新生成（有缓存）

## 表演说明怎么写

先通读整期，找出每句在叙事里的作用（抛悬念、自嘲、数数、转折、揭晓、号召），再写它**怎么说**：

1. **情绪和态度**：带着点不甘心 / 有点无奈 / 真诚地问观众 / 带点小得意 / 恍然大悟。从 SCRIPT 的 `Emotion` 和上下文推，别只写「开心」「平静」
2. **节奏**：语速稍快 / 放慢一点 / 一个接一个地数 / 干脆利落地收一句
3. **停顿和轻重**：稍微停顿了一下再说 / 把数字说得清楚有力 / 重点词加重（参考 SCRIPT 的 `重点词`）
4. **句与句的关系**：「接着」「然后语气转为」「最后」，让模型知道这是连着说的一段话

一句说明管一到两句台词。列举、数字多的句子要单独交代（「把数字说得清楚有力」），否则容易念快、念糊。

## 不要这样写

- **不要在引号里加字**：「呃」「嗯」、重复、改说法都会让字幕和原稿对不上，`--check` 直接报错。想要随意感，写在引号外：「说得很随意，像想到哪说到哪」
- **不要用括号写舞台指示**夹在台词里，如 `"可我（叹气）一条都不想发"`：括号里的字可能被读出来
- **不要写和台词矛盾的情绪**：台词在自嘲，说明却写「激动地宣布」，模型会两头不靠
- **不要每句都写「加重」「停顿」**：处处强调等于没有强调，一段里挑两三处
- 官网技术讲解 demo 那种「吞吞吐吐、吸口水、一些无法分辨的内容」适合模仿真实访谈，**不适合**我们要配字幕的口播

## 生成后怎么验收

- 听：像不像在说话，有没有哪句像念稿、哪个词读错
- 读错的词：在引号外交代读法，如「其中 AI 两个字母分开读」；还不行就换个说法改 SCRIPT
- 某段整体不满意：只改这一段的说明重新生成（提示一变缓存就失效）；每次生成会有随机差异，同一份说明多生成一两次挑最好的也可以
